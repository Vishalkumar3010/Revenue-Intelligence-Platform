
# System Architecture

## Backend Engine

The backend processing engine:
- loads operational transaction data
- validates pricing logic
- resolves historical contracts
- calculates revenue/cost/margin
- generates structured analytical outputs

## Frontend Dashboard

The frontend dashboard provides:
- interactive KPI analytics
- financial visualizations
- outlet intelligence
- operational debugging
- export workflows

## Processing Flow

Transaction Data
    ↓
Pricing Resolution
    ↓
Cost Resolution
    ↓
Margin Calculation
    ↓
Validation & Debugging
    ↓
JSON Output
    ↓
Dashboard Visualization
